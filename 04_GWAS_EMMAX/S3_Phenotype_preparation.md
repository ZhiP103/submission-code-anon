# Algorithm S3. Phenotype preparation

```
INPUT:  phenotype table of each trait
OUTPUT: one phenotype file per trait, three columns

1  read the phenotype table, one row per material
2  keep the columns family id, individual id and phenotype value
3  order the rows exactly as the samples of tfam
4  write missing values as NA
5  write one phenotype file per trait
6  return the phenotype file of each trait
```
